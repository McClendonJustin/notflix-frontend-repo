# Selection - `/selection`

## On this page

- Nav Icon
    - Clicking this icon should bring up a menu on the left-hand side of the page
        - This menu should have a search bar at the top where a user can directly search for a selection by title.
        - Under this search bar should be:
            - A History Button, where a user can see their viewing history, the last 10 items, which should extend down below the History link as a dropdown of sorts
            - A Favorites Button, where a user can see any items that they have favorited, this should also extend down below the favorites button as a dropdown of sorts
            - A Genres Button, where a user can select to view a pre-filtered set of selections based on their choice, the Genre options should extend down below the Genre button as a dropdown of sorts

- Primary Selection Area
    - This area should take up majority of the page, as a cascading set of images each showcasing the title art for the various movies/tv shows we have available.

- Selection Modal
    - When a user clicks on a selection, a modal should popup that has the title of their selection in the top-left, followed by a large preview image from a scene within the selection, or just the cover art if that is all that is available, and below the art should be an area for a description of the selection.
        - Within the Preview Area should be a Play Button, which upon being clicked, navigates to the Cinema window and the feature begins
